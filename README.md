# 🐍Pygame Cheatsheets🐍

Minimal, runnable Pygame examples.

This repo is a fast reference while learning Pygame.

Each file demonstrates one core concept with clean, essential code.

---

## 🎯Purpose

Quick reference.
No fluff.
Just essentials.

---

## Requirements

* Python 3.x
* Pygame

Install pygame:

```bash
pip install pygame
```

---

## 📁Structure

* `core/` → game loop, delta time
* `drawing.py` → shapes, rects, surfaces, text
* `input.py` → keyboard & mouse
* `movement.py` → movement logic
* `collision.py` → rect collision
* `assets.py` → images & animation
* `audio.py` → sound & music
